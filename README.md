# Aarohh Website

Official web application and landing portal for the **Aarohh** lifestyle and fitness platform.

## 🚀 Live Deployment
- **Live URL**: [https://rajtiwarii.github.io/eurocarz/](https://rajtiwarii.github.io/eurocarz/)

## 📁 Project Structure
- `index.html` - Main landing page showcasing Aarohh platform features
- `careers.html` - Careers and open roles
- `dashboard/` - User dashboard and progress views
- `privacy/` - Privacy policy
- `profile/` - Athlete profile and biometric settings
- `subscribe/` - Premium membership plans
- `login/` & `signup/` - Authentication flows
- `assets/` - Brand logos, mockups, and UI graphics
- `style.css` - Global styling and responsive theme
