# EuroCarz — Premium European Luxury & Exotic Car Rental

![EuroCarz Banner](https://images.unsplash.com/photo-1614162692292-7ac56d7f7f1e?auto=format&fit=crop&w=1200&q=80)

**EuroCarz** is a luxury automotive showcase and booking platform featuring European supercars, luxury sedans, and exotic SUVs (Porsche, Mercedes-AMG, BMW M, Audi RS, Lamborghini, Ferrari, and Range Rover).

## 🚀 Live Website
The website is live on GitHub Pages:
**[https://rajtiwarii.github.io/eurocarz/](https://rajtiwarii.github.io/eurocarz/)**

## ✨ Features
- **Curated European Supercar Fleet**: Real-time showcase of Porsche 911 GT3 RS, AMG G63, M8 Competition, RS6 Avant, Huracán Evo, and Ferrari F8.
- **Interactive Filtering & Search**: Instant filter by brand (Porsche, AMG, BMW, Audi, Lamborghini, Ferrari) and body type.
- **Car Detail Modal View**: Deep-dive vehicle specifications (Horsepower, 0-100 km/h, Top Speed, Handcrafted Engine stats, and OEM warranty).
- **VIP Reservation Engine**: Date picker, doorstep delivery preferences, self-drive vs. chauffeur toggles, and instant booking confirmation.
- **Modern Dark Luxury Aesthetic**: High-contrast obsidian theme with subtle gold highlights and glassmorphic navigation.

## 🛠 Tech Stack
- HTML5 / Vanilla JavaScript (ES6+)
- Tailwind CSS
- GitHub Pages Deployment
